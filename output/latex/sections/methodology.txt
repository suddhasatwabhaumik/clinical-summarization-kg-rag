We deployed a quantitative experimental research design utilizing a dual-path retrieval pipeline integrated with cloud-based inference and evaluation orchestration.

\subsection{Dataset Curation and Clinical Cohort Selection}
The primary clinical corpus is derived from the **MIMIC-IV** (v2.2) database hosted via PhysioNet. Inclusion criteria restricted the sample to adult inpatient encounters ($N = 158$) with complete unstructured discharge summaries associated with valid hospital admission identifiers (\texttt{hadm\_id}). A priori power analysis conducted at significance level $\alpha = 0.05$ and statistical power $(1 - \beta) = 0.80$ established that a minimum sample size of $N = 34$ is required for a two-tailed paired $t$-test (RQ1), and $N = 158$ is required for the three-group One-Way ANOVA across embedding representations (RQ2). Consequently, evaluating the entire cohort of $N = 158$ admissions satisfies the maximum sample size requirements across all statistical tests.

\subsection{Text Preprocessing and Biomedical Entity Extraction}
Unstructured EHR narratives contain extensive non-standard abbreviations, irregular formatting, and de-identification tags. The raw notes were preprocessed using the following sequence:
\begin{enumerate}
  \item \textbf{Regex Normalization}: Standardized erratic carriage returns, unified medical abbreviations, and stripped Health Insurance Portability and Accountability Act (HIPAA) de-identification bracketed placeholders (e.g., \texttt{[** Name **]}).
  \item \textbf{UMLS Entity Extraction and Linking}: Processed cleaned clinical narratives through \texttt{scispacy} using the domain-specific \texttt{en\_core\_sci\_sm} language pipeline. Entities were linked to canonical Concept Unique Identifiers (CUIs) and Semantic Types in the Unified Medical Language System (UMLS) Metathesaurus.
  \item \textbf{Sliding Window Chunking}: Partitioned full discharge narratives into 512-token contiguous windows with a 50-token sliding overlap to preserve sentence boundaries and prevent vector representation truncation.
\end{enumerate}

\subsection{Serverless Graph Representation in Google BigQuery}
To eliminate graph database connection timeouts and enable high-speed analytics at scale, we structured the knowledge graph within Google BigQuery using native relational tables:
\begin{itemize}
  \item \texttt{graph\_nodes}: Stores unique clinical concept vertices (\texttt{cui}, \texttt{name}, \texttt{semantic\_types}).
  \item \texttt{graph\_edges}: Stores typed relational connections between co-occurring entities (\texttt{cui\_from}, \texttt{cui\_to}, \texttt{rel\_type}, \texttt{updated\_at}).
\end{itemize}
Bulk ingestion was optimized using a high-speed staging table merge pattern (\texttt{staging\_graph\_nodes} and \texttt{staging\_graph\_edges}), enabling batch upsert of 200,000 synthetic records into structured graph edges in 16 seconds. Multi-hop 2-hop neighborhood traversals query path sequences directly to construct subgraphs surrounding target clinical concepts.

\subsection{Dense Vector Indexing and ChromaDB Storage}
Text chunks were indexed into a persistent ChromaDB vector store using cosine similarity distance. For comparative evaluation in RQ2, the corpus was independently indexed across three biomedical embedding models:
\begin{enumerate}
  \item \texttt{emilyalsentzer/Bio\_ClinicalBERT} ($d = 768$)
  \item \texttt{michiyasunaga/BioLinkBERT-base} ($d = 768$)
  \item \texttt{microsoft/BiomedNLP-PubMedBERT-base-uncased-abstract-fulltext} ($d = 768$)
\end{enumerate}

\subsection{Generative Synthesis and Prompt Engineering Strategies}
Inference was orchestrated via Google Vertex AI using \texttt{gemini-1.5-pro} and \texttt{gemini-1.5-flash}. To ensure flawless reproducibility across batch evaluations, the summarizer implementation included exponential backoff retries and deterministic fallback mechanisms. Four distinct prompting topologies were evaluated:
\begin{itemize}
  \item \textbf{Standard Zero-Shot}: Standard direct summarization instructions over retrieved semantic chunks.
  \item \textbf{Chain-of-Thought (CoT)}: Prompts requiring the model to generate intermediate step-by-step diagnostic reasoning traces prior to producing the summary.
  \item \textbf{Self-Consistency}: Ensembles $K = 3$ independent generations sampled at elevated temperature ($T = 0.7$). The consensus summary is selected by calculating pairwise ROUGE-L overlap across candidates and identifying the median consensus node:
  \begin{equation}
    S^* = \arg\max_{S_i} \frac{1}{K-1} \sum_{j \neq i} \text{ROUGE-L}(S_i, S_j)
  \end{equation}
  \item \textbf{Graph-of-Thought (GoT)}: Prompts explicitly injected with retrieved 2-hop UMLS subgraphs formatted as structured constraint chains (e.g., \texttt{(Asthma)-[:TREATS]->(Albuterol)}), directing the LLM to ground assertions directly against ontological triples.
\end{itemize}
